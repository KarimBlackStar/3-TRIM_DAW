# 🧾 Sintaxis Markdown utilizada

- `#`, `##` → Títulos y subtítulos  
- `-` → Listas  
- `1.` → Listas numeradas  
- `**texto**` → Negrita  
- `\` → Escapar caracteres (`\#`, `\**`)  
- ``` ``` → Bloques de código  
- ```javascript → Código con lenguaje  
- ```mermaid → Diagramas  
- `![texto](imagen)` → Imágenes  
- `[texto](url)` → Enlaces  
- `| | |` → Tablas  
- `:---`, `---:` → Alineación en tablas  
- `$...$` o `$$...$$` → Fórmulas matemáticas  
- `:` → Emojis (`:white_check_mark:`)  
- `+` → Lista alternativa
