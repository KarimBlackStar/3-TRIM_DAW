# 📘 Guía Rápida de Markdown

> 🧠 Chuleta visual para estudiar y usar en GitHub / Notion

---

## 🏷️ Títulos

```md
# Título 1
## Título 2
### Título 3
```

➡️ Se usan `#` para jerarquía

---

## 📝 Listas

### 🔹 Lista normal
```md
- Elemento
- Elemento
```

### 🔢 Lista numerada
```md
1. Uno
2. Dos
```

---

## ✏️ Texto

```md
**Negrita**
*Cursiva*
~~Tachado~~
```

➡️ **Negrita**, *cursiva*, ~~tachado~~

---

## ⛔ Escapar caracteres

```md
\# No es título
\**No es negrita**
```

➡️ Usa `\` para evitar formato
