## 🏷️ Títulos

```md
# Título 1
## Título 2
### Título 3
```

➡️ Se usan `#` para jerarquía

---

## 📝 Listas


### 🔢 Lista numerada
```md

```

## ✏️ Texto


## Alertas

Las **alertas** se utilizan para destacar información crítica. En GitHub, se muestran con colores e iconos distintivos para indicar la importancia del contenido.[cite: 1]

> [!NOTE]
> Texto

> [!TIP]
> Texto

> [!IMPORTANT]
> Texto

> [!WARNING]
> Texto

> [!CAUTION]
> Texto
